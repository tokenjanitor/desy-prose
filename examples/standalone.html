Ein Stylesheet. Ein Lesetext.

Diese Seite enthält einfaches HTML und das gleiche Prose-Stylesheet wie das Labor. Sie benötigt weder Astro-Komponenten noch JavaScript oder einen zusätzlichen Reset.

Das CSS gestaltet ausschließlich den markierten Textbereich. Schriftgröße, Satzbreite, Zeilenhöhe und Farben lassen sich über Custom Properties anpassen.

Die Form folgt dem Text

Ein Absatz nach einer Überschrift beginnt bündig. Listen und Zitate gliedern den Inhalt, ohne eine Klasse an jedem einzelnen Element zu verlangen.

  • Semantisches HTML.
  • Native CSS-Regeln.
  • Ein dokumentierter Satz an Variablen.

Ein Beispielzitat zeigt einen weiteren Übergang im Textfluss.

.prose {
  --prose-measure: 60ch;
  --prose-line-height: 1.7;
}
